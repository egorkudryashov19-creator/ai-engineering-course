# ai-engineering-course

## Troubleshooting

### 'ascii' codec can't encode characters`
**Что видел:** ошибка при запуске после того, как вписал сломанный ключ.
**Почему:** в `GIGACHAT_CREDENTIALS` попали русские буквы, а ключ уходит в
HTTP-заголовок, где допустим только латинский текст.
**Что сделал:** вернул настоящий ключ (латиница + цифры). Заодно убедился, что
благодаря fallback скрипт не упал, а ответил через `[HuggingFace]`.

### `401 Unauthorized`
**Что видел:** при запуске скрипт писал `401 Unauthorized` от GigaChat,
и ответ приходил только через fallback.
**Почему:** в `GIGACHAT_CREDENTIALS` был указан неверный (или чужой) ключ —
сервис отклонил авторизацию.
**Что сделал:** подставил корректный ключ из личного кабинета GigaChat.
Проверил, что запрос уходит с нужным `Authorization`-заголовком.
